# Zadanie 15: Ulepszone wyszukiwanie składników

**Status:** ✅ Zaimplementowane  
**Priorytet:** 🟢 Niski

## Opis

Zamiana standardowego elementu `<select>` na wyszukiwarkę składników z możliwością filtrowania przez wpisywanie tekstu. Przy 129+ składnikach w bazie, przewijanie listy jest uciążliwe.

## Pliki zmodyfikowane

- `recipes/templates/recipes/index.html` - modal dodawania składników z Tom Select
- `templates/base.html` - dodanie biblioteki Tom Select (CDN)

## Zrealizowane

- [x] Pole tekstowe z podpowiedziami zamiast standardowego `<select>`
- [x] Filtrowanie składników w czasie rzeczywistym podczas wpisywania
- [x] Wyszukiwanie case-insensitive (mąka = Mąka = MĄKA)
- [x] Obsługa polskich znaków diakrytycznych (ą, ę, ó, ś, ć, ź, ż, ń, ł)
- [x] Wyszukiwanie po fragmencie nazwy (np. "mar" → Marchew, Margaryna)
- [x] Wyświetlanie kategorii składnika obok nazwy (np. "Marchew (warzywa)")
- [x] Możliwość wyboru klawiszami (strzałki + Enter)
- [x] Podświetlenie wpisanej frazy w wynikach
- [x] Zachowanie istniejącej funkcjonalności "Utwórz nowy składnik"
- [x] Dostępność (ARIA labels, obsługa czytników ekranu)
- [x] Responsywność na urządzeniach mobilnych

## Implementacja

**Biblioteka:** Tom Select (CDN)

```html
<!-- base.html -->
<link href="https://cdn.jsdelivr.net/npm/tom-select@2.3.1/dist/css/tom-select.bootstrap5.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/tom-select@2.3.1/dist/js/tom-select.complete.min.js"></script>
```
