# Zadanie 06: Obsługa obrazów przepisów

**Status:** ⬜ Do zrobienia  
**Priorytet:** 🟡 Średni

## Opis

Dodanie możliwości uploadu i wyświetlania obrazów przepisów. Pozwoli to użytkownikom wizualizować przepisy na liście i w szczegółach.

## Analiza obecnego stanu

### ✅ Już zaimplementowane
- Model `Recipe` posiada pole `image = models.ImageField(upload_to="recipes/", blank=True, null=True)`
- Biblioteka `Pillow` zainstalowana (wymagana dla ImageField)
- `MEDIA_URL` i `MEDIA_ROOT` skonfigurowane w settings.py:
  ```python
  MEDIA_URL = "/media/"
  MEDIA_ROOT = BASE_DIR / "media"
  ```

### ❌ Brakuje
- Formularz nie ma `enctype="multipart/form-data"` (wymagane dla file upload)
- Brak pola `<input type="file">` w szablonie
- Widok nie obsługuje `request.FILES`
- Brak serwowania plików media w trybie DEBUG (urls.py)
- Brak wyświetlania obrazów w UI

## Pliki do modyfikacji

| Plik | Zmiany |
|------|--------|
| `plannatalerzu/urls.py` | Dodać serwowanie media files (DEBUG) |
| `recipes/views.py` | Obsługa `request.FILES` przy tworzeniu/edycji |
| `recipes/templates/recipes/index.html` | Input file, podgląd, miniaturki |

## Szczegóły implementacji

### 1. Konfiguracja URL-i media (urls.py)

```python
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    # ... istniejące ścieżki
]

if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

### 2. Modyfikacja formularza (index.html)

```html
<!-- Zmiana: dodać enctype -->
<form method="post" enctype="multipart/form-data">

<!-- Nowe pole po kategorii -->
<div class="mb-3">
    <label class="form-label" for="image">Zdjęcie przepisu</label>
    {% if editing_recipe.image %}
    <div class="mb-2">
        <img src="{{ editing_recipe.image.url }}" alt="Aktualne zdjęcie" 
             class="img-thumbnail" style="max-height: 150px;">
        <div class="form-check mt-1">
            <input type="checkbox" class="form-check-input" id="image_clear" name="image_clear">
            <label class="form-check-label small" for="image_clear">Usuń zdjęcie</label>
        </div>
    </div>
    {% endif %}
    <input type="file" class="form-control" id="image" name="image" 
           accept="image/jpeg,image/png,image/webp,image/gif">
    <div class="form-text">Opcjonalne. Max 5MB, formaty: JPG, PNG, WebP, GIF</div>
</div>
```

### 3. Modyfikacja widoku (views.py)

```python
def recipe_index(request):
    # ... w sekcji tworzenia/edycji przepisu:
    
    # Obsługa obrazu
    if 'image' in request.FILES:
        image = request.FILES['image']
        # Walidacja rozmiaru (5MB)
        if image.size > 5 * 1024 * 1024:
            # zwróć błąd
            pass
        recipe.image = image
    
    # Usuwanie obrazu
    if request.POST.get('image_clear'):
        if recipe.image:
            recipe.image.delete(save=False)
        recipe.image = None
    
    recipe.save()
```

### 4. Wyświetlanie miniaturki na liście

```html
<div class="card h-100">
    {% if recipe.image %}
    <img src="{{ recipe.image.url }}" class="card-img-top" alt="{{ recipe.name }}"
         style="height: 180px; object-fit: cover;">
    {% else %}
    <div class="card-img-top bg-light d-flex align-items-center justify-content-center"
         style="height: 180px;">
        <span class="text-muted">🍽️ Brak zdjęcia</span>
    </div>
    {% endif %}
    <div class="card-body">
        <!-- reszta karty -->
    </div>
</div>
```
